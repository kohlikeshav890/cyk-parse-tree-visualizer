CNF Transformation — Theoretical Basis
Theorem (Chomsky 1959): Every CFG L (excluding ε) has an equivalent CNF grammar G′ with L(G′) = L(G).

CNF Definition: G = (N,Σ,P,S) is in CNF iff every production is A → BC (A,B,C ∈ N) or A → a (a ∈ Σ).

CYK Correctness: A ∈ table[i][j] iff A ⟹* w[i..i+j]. The string is accepted iff S ∈ table[0][n−1].

Ambiguity (undecidable in general): Whether a CFG is inherently ambiguous is undecidable, but ambiguity for a specific string is decidable by counting distinct parse trees.
